A clean, responsive digital business card template built with semantic HTML5 and modern CSS.

## 📁 Repository Structure
- `index.html`: Contains the structural content and profile links.
- `style.css`: Contains custom styles, responsive layouts, and CSS variable color tokens.
- `README.md`: Project documentation and quick setup guide.

## 🚀 Features
- **Responsive Layout:** Works smoothly across desktop and mobile browsers.
- **Modern Styling:** Styled using CSS flexbox, CSS variables, and clean micro-interactions.
- **Zero Dependencies:** Pure HTML and CSS with no external frameworks required.
